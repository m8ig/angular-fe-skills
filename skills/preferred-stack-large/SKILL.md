---
name: preferred stack for large projects
description: Use when choosing the tech stack for a new large-scale project. Covers API (NestJS), web (Angular + Ng-Zorro), NX monorepo, Cypress E2E, and hosting choices.
---

1) API - Nest v11
2) web - the latest version of Angular
3) Ng-Zorro as UI library
4) NX monorepo
5) e2e tests - Cypress
6) Brevo for mail delivery
7) github
8) Neon database
9) yandex.cloud to host everything
10) yarm as a package manager

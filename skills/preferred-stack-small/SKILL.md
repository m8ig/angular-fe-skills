---
name: preferred stack for small projects
description: Use when choosing the tech stack for a new small or medium project. Covers API (NestJS), web (Next.js + Tailwind), optional NX monorepo, and Cypress E2E.
---

1) API - Nest v11
2) web - the latest version of Next.js
3) Tailwind as UI library
4) NX monorepo *(optional)*
5) e2e tests - Cypress
6) Brevo for mail delivery
7) github
8) Neon database
9) yandex.cloud to host everything
10) yarm as a package manager
